# Keyboard Shortcuts

There are only a few global shortcuts at the moment — enough to save clicks without turning Jupiter into a keyboard-memory test.

| Shortcut | Action |
|---|---|
| `Ctrl` + `` ` `` | Toggle the terminal panel |
| `Meta` + `.` | Cycle the selected agent |
| `Meta` + `Shift` + `D` | Cycle the thinking level |

On macOS, `Meta` is the Command key.

Repeated keydown events are ignored, and the normal composer controls remain available for everything else.
