Lifecycle hooks

Hooks run asynchronously in Bash using /bin/bash, with /tmp as the working directory. A hook failure does not change the agent or subagent lifecycle result; the timeout applies to each hook.

These runtime variables are always available: JUPITER_PROJECT_NAME (project name), JUPITER_WORKSPACE_NAME (workspace name), and JUPITER_SESSION_NAME (session name). Project-configured environment variables are also passed and can be expanded normally, such as "$WEBHOOK_URL". The three JUPITER_* values take precedence over project variables with matching names.

Example:

printf '%s | %s | %s\n' "$JUPITER_PROJECT_NAME" "$JUPITER_WORKSPACE_NAME" "$JUPITER_SESSION_NAME" >> /tmp/jupiter-hooks.log
